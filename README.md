## Descripción

Este proyecto fue desarrollado como parte del Trabajo Práctico de Organización Empresarial, aplicando herramientas de control de versiones, gestión de proyectos y análisis de datos.

El objetivo principal fue implementar un flujo de trabajo reproducible utilizando GitHub, Jira y Google Colab, además de desarrollar un script en Python para analizar un dataset y generar resultados automáticos.

---

# Tecnologías Utilizadas

* Python
* Git y GitHub
* Jira
* Google Colab
* Pandas
* Matplotlib

# Funcionalidades

El script desarrollado permite:

* Leer datos desde un archivo CSV.
* Procesar información de ventas.
* Generar gráficos automáticamente.
* Guardar resultados dentro de la carpeta `/resultados`.
